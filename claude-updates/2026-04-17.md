# Claude 官方更新摘要 · 2026-04-17

## 📝 摘要
Anthropic 于 4 月 16 日正式发布 Claude Opus 4.7，在高级软件工程和视觉能力上显著提升，同时引入 xhigh 推理级别和 token budgets 功能。Claude Code 同步更新至 v2.1.112，新增 /tui 全屏模式、/ultrareview 多代理代码审查、推送通知等重要功能。Python/TypeScript SDK 同步更新以支持新模型。

## 🆕 新增/更新功能

### Claude Opus 4.7 正式发布
- **产品线**：API / 消费端
- **用途**：最强通用模型，在复杂推理、智能编程和多步骤任务中大幅提升表现
- **关键改进**：
  - 软件工程能力显著超越 Opus 4.6，尤其在高难度任务上提升明显
  - 视觉能力提升 3 倍以上：长边最高支持 2,576 像素（约 375 万像素）
  - 新增 `xhigh` 推理级别（介于 high 和 max 之间），推荐用于高级编程和复杂代理任务
  - 新增 token budgets 功能（公测）用于引导 token 分配
  - 自我验证能力：在报告结果前自动校验
- **定价**：$5 / 百万输入 token，$25 / 百万输出 token（与 Opus 4.6 持平）
- **模型 ID**：`claude-opus-4-7`
- **小示例**：
  ```python
  import anthropic
  client = anthropic.Anthropic()
  response = client.messages.create(
      model="claude-opus-4-7",
      max_tokens=16384,
      thinking={"type": "adaptive"},
      messages=[{"role": "user", "content": "Analyze this codebase and suggest refactoring opportunities."}]
  )
  ```
- **文档**：[Introducing Claude Opus 4.7](https://www.anthropic.com/news/claude-opus-4-7) / [What's new](https://platform.claude.com/docs/en/about-claude/models/whats-new-claude-4-7)
- **推出日期**：2026-04-16

### Claude Code v2.1.111 — Opus 4.7 集成与多项新功能
- **产品线**：Claude Code
- **用途**：CLI 工具重大更新，集成 Opus 4.7 xhigh 推理、自动模式、全新技能和审查工具
- **关键变化**：
  - Opus 4.7 xhigh 推理级别可用，通过 `/effort` 命令调节
  - `/effort` 现为交互式滑块，支持方向键导航
  - Auto 模式对 Max 订阅者开放（使用 Opus 4.7 时），不再需要 `--enable-auto-mode`
  - 新增 `/ultrareview` — 使用并行多代理进行全面代码审查
  - 新增 `/less-permission-prompts` 技能 — 扫描对话记录，自动生成权限白名单建议
  - 新增 "Auto (match terminal)" 主题选项，自动匹配终端暗/亮模式
  - Windows: PowerShell 工具逐步推出（通过 `CLAUDE_CODE_USE_POWERSHELL_TOOL` 配置）
  - 计划文件按提示内容命名（如 `fix-auth-race-snug-otter.md`）
  - 带 glob 模式的只读 bash 命令不再触发权限提示
- **小示例**：
  ```bash
  # 调整推理级别
  /effort xhigh
  
  # 使用并行多代理代码审查
  /ultrareview
  
  # 自动生成权限白名单
  /less-permission-prompts
  ```
- **文档**：[Claude Code Releases](https://github.com/anthropics/claude-code/releases)
- **推出日期**：2026-04-16

### Claude Code v2.1.110 — TUI 全屏模式与推送通知
- **产品线**：Claude Code
- **用途**：新增全屏无闪烁渲染模式和移动端推送通知支持
- **关键变化**：
  - 新增 `/tui` 命令和 `tui` 设置 — 全屏无闪烁渲染
  - 新增推送通知工具（需启用 Remote Control 和 "Push when Claude decides" 配置）
  - 新增 `autoScrollEnabled` 配置项（全屏模式）
  - `--resume`/`--continue` 现可恢复未过期的计划任务
  - 改进 `/doctor` 的 MCP 服务器配置警告
- **小示例**：
  ```bash
  # 启用全屏 TUI 模式
  /tui
  
  # 或通过设置持久化
  claude config set tui true
  ```
- **文档**：[Claude Code Releases](https://github.com/anthropics/claude-code/releases)
- **推出日期**：2026-04-15

- **产品线**：API（SDK）
- **用途**：SDK 同步支持 Claude Opus 4.7 模型、token budgets 和 user_profiles

### Claude Sonnet 4 / Opus 4 模型弃用公告
- **产品线**：API
- **用途**：旧版模型弃用通知，建议迁移至新版
